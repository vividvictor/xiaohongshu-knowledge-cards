# 排版系统

需要选择密度、视觉风格、信息布局或调整 `visual_ratio` 时读取本文件。

## 设计目标

知识卡片不是海报。封面需要一眼可读，正文需要在手机上高效承载信息。借鉴成熟设计 skill 的方法时保留三点：风格与布局分离、四级字阶、网格与安全边距；不照搬“90% 视觉、10% 文字”的海报比例。

## 两个独立维度

先选信息布局，再选视觉风格。不能用“可爱”“极简”代替内容结构。

### 信息布局

| 布局 | 推荐内容 | 容量 |
|---|---|---:|
| `dense` | 知识卡、速查表、方法论 | 5—8 个短要点 |
| `list` | 清单、排行、注意事项 | 4—7 项 |
| `comparison` | 误区/正解、前后、优缺点 | 左右各 2—5 项 |
| `flow` | 流程、因果、时间顺序 | 3—6 步 |
| `grid` | 并列概念、术语、数据点 | 2—6 格 |
| `sparse` | 封面、金句、单一结论 | 1—2 个信息点 |

JSON 用 block 类型表达布局：`fact_grid` 对应 `grid`，`comparison` 对应左右对比，`flow` / `steps` 对应过程。不要额外添加只影响措辞、不影响渲染的伪布局字段。

### 视觉风格

根据内容选一个风格方向，并在整套卡片中保持一致：

- `editorial`：清晰网格、克制色彩、杂志式层级；默认选择。
- `notion`：简洁线稿、理性、轻手绘；适合方法与概念。
- `study-notes`：批注、高亮、学习笔记感；适合复习与教程。
- `bold`：强对比、大标题、警示色；适合避坑和观点。
- `screen-print`：有限色、网点与象征图形；适合文化评论和故事。

风格用于封面/插图提示词和调色板，不改变事实内容。避免模仿在世艺术家或受保护作品。

## 密度档位

`density` 控制整套卡片的字号、边距、行距、模块间距和 AI 内容图比例。

| density | 正文字号基线 | AI 内容图默认高度 | 用途 |
|---|---:|---:|---|
| `dense` | 30px | 32% | 默认；约 180—320 个中文字符 |
| `balanced` | 33px | 40% | 常规图文混排 |
| `airy` | 36px | 48% | 金句、情绪、少量信息 |

上述字号以 `1080x1440` 为基准，其他尺寸按宽度同比缩放。正文不低于 30px 基线；需要更大容量时先压缩冗句、改用网格、降低内容图比例或拆页。

## 四级字阶

1. 封面标题：唯一视觉钩子，最多 3 行。
2. 页标题：说明本页回答什么，最多 2 行。
3. 正文与模块标题：正文常规字重，关键短语加粗。
4. 元信息：总标题、页码、标签，只做导航。

同页最多两个主要字重。大标题负责层级，不靠堆叠描边、阴影或多色渐变制造重点。

## 网格与构图

- 使用统一左右安全边距；正文所有模块对齐同一主轴。
- 封面图可全幅，但标题必须落在暗罩或稳定留白上。
- 内容页有图时使用上下分区；无图时从页标题开始连续排布。
- 对比必须等宽；事实卡优先两列；流程每行最多三格。
- 颜色最多三种：背景、正文、强调。透明度变化不算新颜色。
- 精修优先调整对齐、间距和层级，不靠增加装饰补救。

## 文字容量决策

按此顺序解决装不下：

1. 删除重复修饰和不服务主线的句子。
2. 把段落改成短句、事实格或对比列。
3. 把 `visual_ratio` 降到 `0.26`，前提是图片仍能看清。
4. 使用 `density: "dense"`。
5. 拆成下一页，下一页标题写 `接上页` 或更具体的承接标题。

禁止直接截断文字、跳过后续 block，或把字号降到难以在手机上阅读。
